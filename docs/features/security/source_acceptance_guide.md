**Android 已完成本地交付与M对账。以下English入口已实施，并已运行host、插件及指定Android设备验证；支持与限制见正文。**
契约见[来源接受设计](source_acceptance_design.md)，能力边界见本指南；受测版本与实证见[交付验证记录](https://github.com/IdVincentYang/FlClash/blob/bc25dec0dcf955baec07e362f74502e867efb88e/docs/features/security/loop2/l2_t05_result.md)。

这些新增入口和运行期能力仅面向Android。非Android保持原来源、脚本、provider与输入路径，
不显示Source permissions，也不把既有运行状态标为已受此契约保护；其它平台安全能力尚未覆盖。
指定Android AVD已运行受控服务、后台更新及恢复验证；实际覆盖和未验证限制见上述记录。
设备与host结果不构成真实TUN入站或物理网络保证。

## 首次使用和自动维护

Import下载来源后，在Review source核对用途、来源origin、协议能力、DNS与默认出口。
Accept this revision只接受这一份内容；选择范围内自动维护才允许未来普通更新。
来源名称／摘要不显示URL token和密码。节点来源可信决定不保证节点没有恶意行为。
材料确认与正式保存分开：拒绝或格式检查失败保留适用旧材料和权限；同意新来源不会提前取消本次接收。
保存跨权限／文件／DB失败时显示未完成的本地提交并阻止自动恢复；须在前台核对实际保存内容后重新构建。
若前端断开时仍有不能确认结束的写入，Source permissions显示必须完整退出应用进程：打开Android的App info → Force stop，再重新打开FlClash。
关闭界面／划掉任务、Restart proxy或重启Service不能证明写入结束，也不会解除提示。重新打开后仍须明确确认本地材料核对；候选不会自动变成许可。
耐久屏障、真正未知写者、实际Force stop及显式恢复已在指定AVD验证；这些受控进程与guest loopback结果不替代真实TUN／物理网络覆盖。
仅确认候选不能运行它，应用重启也不会把未完成候选自动提升为正式许可。材料提交和未知写者恢复已通过受控host及指定AVD验证；完整覆盖和设备限制见验证记录。

普通provider内容更新局部采用并保留DIRECT和未变化provider的已有连接；host及指定AVD已验证TCP／UDP与普通前端detach，不构成任意设备、真实TUN入站或物理网络保证。
已有socket不会被迁移到新节点，普通删改与明确撤回当前使用的处置不同。下载成功／材料已接受也不等于已采用。
已应用但恢复保存失败时明确显示“已应用，恢复未保存”，继续当前连接并禁止重放旧checkpoint；重试只保存已应用事实。
活跃旧连接占用退休材料预算时可能延后后续采用，不能静默关闭连接或回收其对象。

重新启动服务可复用仍有许可的已接受provider材料，不会为了启动自动改用DIRECT。
没有合格材料时仍按原下载模式或显式引导处理；准备阶段失败会结束本次启动，不擅自接受候选。

恢复后的重建缺少可用HTTP(S)材料时，前台会逐来源询问是否允许本次Direct请求，显示来源名称和目标origin。
只有确认才下载，下载后的新内容仍要按来源权限接受；本地文件不会显示网络引导，声明Proxy的来源不会改走Direct。
取消后可以再次点击Start重试；自动／后台路径不继承本次许可，新Stop或运行命令胜过旧请求；原恢复／Start资格必须跨队列保留，不能改认新命令，恢复或Start等待期间，新命令或新配置应用胜过旧请求；旧请求结束不会取消较新的配置应用。此并发保护已完成受控测试和指定AVD启动／停止正对照，整项实现评审已通过。
此引导已实现并在指定Android AVD通过真实失败保存、离线核对、取消及再次Start的guest loopback验证；整项实现评审已通过，不能据此推导物理网络或TUN入站保证。

## Inline内容更新的限制

Inline update pending表示本次节点／组变化需要换代理图，但当前运行期仍可能有未同步的读者；保留旧配置，列出具体原因。
未满足封闭R1形状的规则变化、provider声明或其它运行结构变化，以及节点／组和规则或provider正文同时变化，首版同样保旧并要求前台采用。
普通刷新不会因此自动重启服务；材料保存和当前采用仍分开显示。
首版可支持无fragment的普通UDP／TCP／DoT和禁H3的DoH；应用默认DoH＋UDP bootstrap仅就DNS条件可满足，仍需其它资格。
DoQ／DoH3、命名DNS、respect-rules、DHCP、私有DNS，或当前进程曾创建这些客户端，都会使inline自动采用待处理。
改成安全DNS或Stop不能证明旧调用退出，不能据此立即放开；不要为了更新被迫改DNS或出口。
明确前台采用与后台自动维护分开，前台须说明实际连接影响；普通provider热更新继续按自身资格处理。

## 自有分流与高影响变化

Routing rules选择Do not use source routing rules后维护自有路由，明确Unmatched traffic为代理、DIRECT或REJECT。
清空自有规则不会恢复源规则；未指定默认或目标失效时须完成设置，不能自动直连。
Override的各模式均提供Match target；选择明确出口作为自有规则的默认，Follow profile不能代替这项明确选择。
节点、节点组、DNS与其它能力分别选择；此开关不会连带批准其它用途。

Review changes解释解析服务、默认出口、固定保护、控制服务或来源等有效变化。
拒绝／过期在提交前保留合资格旧输入；需要确认的候选不会因后台重复刷新而重复弹窗。
不认识的能力须明确审查，Accept不能绕过禁止用途或真实工厂拒绝。
已批准自动规则维护限设计中明确的固定保护／可变条件形状；复杂规则可逐版本接受，不要求强制转为受管策略。

## Script、撤回和恢复

Review script先核对代码与可读配置／console能力，再接受精确代码版本；未接受不执行预览。
接受代码后仍要审查其输出，代码授权不等于任意输出获准；不把console当作全面脱敏保证。

Stop automatic maintenance只关闭未来自动维护，精确已接受版本可继续使用和本机重启。
Stop using this source/capability会停止依赖它的当前配置并禁止重放，须另选不依赖它的输入。
Profile菜单中的Review source直接进入来源审查；Profile编辑页的Source permissions及Script菜单中的同名项分别管理各用途权限。
Profile卡片只在当前内容或关联来源需要审核时显示“待审核”并进入审核，其余点击进入编辑；检查未完成或失败仍可编辑，失败提供手动重试。“使用”按钮独立切换订阅，待审核时须先完成审核。状态检查只读本地内容及正式许可，不下载、不创建候选或授予许可。
被动自动应用及后台刷新不弹出新接受窗口；窗口可见也不代表用户正在批准来源。停止使用后可从权限入口主动重新审查。
启动时被动恢复仅复用已审核的汇总快照或旧版完整检查点，不联网补齐缺失的关联材料；没有合资格快照时提示需要来源审核。
配置重新应用、初始化及延迟重试默认不允许打开审核窗口；缺少Profile文件也不启动交互下载。只有明确的前台操作可请求审核，切后台会取消窗口和其材料会话，回到前台不会自动补弹；未确认内容不获授权。
已审核且未撤回的完整配置可在后台恢复，运行中的合资格旧配置不因新版本待审而等候弹窗。首次使用、没有完整许可或许可被撤回时，需要用户在前台主动审核。
用户点击通知栏／快捷开关而启动失败时，显示系统提示，指向应用内的来源审核或错误详情；普通自动初始化不显示该提示。失败反馈核对原生请求号和进程代次，已被新请求取代的结果不再提示。
关联材料加载失败与权限存储读取／核验失败分别提示，应用日志只记录来源操作及错误代码，不以“等待Core就绪”代替全部失败原因。
Review source按订阅汇总审核：同一窗口展示原始Profile、最终配置及其引用的节点来源和规则集，加载完成后统一确认。
点击Review source后先立即显示检查进度，再在同一窗口列出全部关联来源。每项显示等待、下载、核验、就绪或失败，最多并发3项。失败项独立重试，成功项保留；声明匹配且许可仍有效的已审核快照优先复用，并在当前配置上下文重新核验，核验仍在本次确认前完成。
预览仅解析和读取材料，不授予许可；全部关联来源就绪前不能接受不完整的汇总。
URL 导入完成审核与保存后，若它是唯一的订阅且当前没有选择，自动将其设为当前订阅；不会自动 Start。已有选择保持不变，保存待补齐的未审核材料不自动使用。
URL 新导入在全部关联来源均尝试结束后，若仍有失败，可选“保存待补齐”：保留原材料但仍须审核，不能直接使用。
或选“审核可用配置”：保留成功加载的规则集、节点来源、原有可用分组和 DNS，以及仍获许可的匹配旧快照。
下方列出缺失来源、必须停用的规则／分组及保留的默认出口；再次点击 Accept 才保存派生配置。
已有订阅的前台更新及 Review source 同样支持此操作。成功材料在本次审核内复用，不重新下载。
URL 保留但部分配置关闭自动更新；手动更新后重新审核完整配置。
缺失内容影响 DNS、默认出口或无法可靠处理的复杂依赖时，显示阻塞位置，不能接受部分配置；不会注入自动直连。
只要仍有来源排队、下载、核验或重试，以上接受和替代操作均不可用。Final configuration 的“已解析”仅表示预览解析完成。
部分配置验证及限制见[方案与验证](../profiles/partial_configuration_plan.md)，原仅节点方案保留为[历史结果](../profiles/partial_import_result.md)。取消或切后台立即关闭窗口并取消所属加载会话，迟到结果不会补弹窗口。
统一确认仅覆盖本次展示的精确快照，随后仍按各用途分别登记正式许可。已审核的关联快照可在重启或切换订阅时复用；撤回许可后不能复用。
新版本超出已允许的维护范围时须重新汇总审核，不为每个节点逐一弹窗。Script代码仍须先独立接受精确代码版本，未授权代码不执行预览。
取消、切换Profile或新的运行操作不会让旧审核继续应用。仅打开／退出编辑页不会重新应用配置。
外部导入／备份恢复需重新接受，不复制原机器的委托。

## 查看连接来源

Live connections／Recent requests详情显示Matched rule、Source、Applied revision与外层Rule set。
版本属于实际匹配时的输入，切换Profile后不会用新配置重算旧连接。
Unknown表示证据缺失、超限、恢复遗留或无法唯一对账；多个候选表示Script等变换无法证明唯一作者。
Rule set只说明外层集合和材料版本；节点provider链不能代替规则来源。
这些入口不采集HTTPS路径，不提供App持久分流或网络活动聚合。
