# Android 本地故障报告使用指南

当前 Android 实现提供本地报告管理和主动导出，已做合成消费者验证；真实系统环境限制见文末。
正式行为与采集边界见[报告契约](crash_reports_design.md)。

## 查找与理解报告

从“工具 → 其它 → 本地故障报告”进入；无需开启普通日志。
列表显示跨启动保留的报告、来源、时间、版本及占用；点开查看受控摘要。
保存最多 20 份、16 MiB、30 天，自动清理为尽力维护，未知或损坏项也占容量。

仅元信息表示没有取得 trace，同一系统记录不会自动补齐；截断的 protobuf 不是完整 dump。
缺失原文、未知格式、损坏和身份未知各有提示；未核验表示尚未检查原文校验和。
版本未知不会拿当前版本代替，摘要也不表示已经符号化。

## 删除与刷新

详情删除当前报告，列表可确认删除当前快照中的全部报告；新收集项可能在刷新后出现。
部分失败时检查剩余项并重试。未知或损坏报告可以删除，快照过期需刷新重新选择。
删除仅处理应用私有报告正文，保留内部去重状态及已导出的副本，也不会关闭后续采集。
同一系统缓存报告或当前进程重复异常仍可能被去重。

## 选择导出

默认导出受控摘要 JSON，不含异常原文。确需修复材料时另选原始导出，阅读敏感内容警示后确认，
得到含摘要和 raw.bin 的 ZIP；原文缺失、未知或校验失败时不能导出原始材料。
随后在系统选择器选择保存位置。位置可能由云端提供方同步，确认前核对接收方与用途。
应用不会自行发送邮件、WebDAV 或自动上传报告。

成功写入且读回一致才表示目标字节已核验；提供方不允许读回时显示“已写入，目标内容未核验”。
取消、退出、旋转或失败会尽力清理本次文档，提供方可能已收到部分数据或留下副本，应在目标检查。
应用不能撤回云端已收到的内容；删除私有报告也不删除这些副本。
超时不代表底层 I/O 已停止，队列忙时稍后刷新，不能把忙／取消解释为报告丢失或清空成功。

## 验证限制

真实系统选择器、设备退出材料、云端同步和设备迁移尚未验收；合成消费者的通过不能代替这些环境。
既有普通日志仍可能含秘密，报告摘要保护不表示已完成全部日志脱敏。
