## 验收与接续

- T01只交付随包基线和可复核结论，不把现有私有文件或任意自定义来源自动记为可信，也不声称已保护全部运行入口。
- T02覆盖来源／格式／摘要错误、并发切换、取消迟到、磁盘失败和重载失败；没有适用基线时明确失败，不删除规则或默认DIRECT。
- T03分别核发布身份、传输完整性、分类结果和最终路由，正常DIRECT／代理规则均可用；不以分类样本证明整个数据集准确。
- 每项设计通过后连续实施和自验，经M实现评审再正常本地提交／合入／清理；M独立收尾及普通push并核远端后接下一项。D不push。
- 原始比对、下载和运行证据保存在忽略的`build/verification/l6-t01/`及后续对应任务目录；正式工具／基线随源，长期规则在所属契约维护，不复制平行台账。
