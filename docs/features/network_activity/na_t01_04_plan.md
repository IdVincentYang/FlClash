# 04 目标连接详情 Plan

任务入口：[NA-T01-04](network_activity_tasks.md#na-t01-04-目标活动详情只读页)，实施基线 `a0c1197`。
用户已确认按当前可取得的连接事实交付第三层，逐条连接不合并，不新增完整 URL／HTTP 请求采集。

## 页面与操作

从某 App 的目标列表点击 Host／IP 进入；目标列表不再展开规则组合。
详情标题为目标，下面保留 App 范围和已观察目标 IP／端口、协议及可用地区／ASN，地址可复制，超过三项折叠。
不重复前两层活动统计、规则／出口汇总，也不显示搜索框。
连接按开始时间倒序，每个原连接 ID 一项；后续快照仅刷新同一项流量和存活状态。
ID 可复制完整值，直接显示上传／下载、实际出口链路及规则；展开查看地址、时间、来源和配置版本。
ID 与流量复用第二层正活跃值的强调色与字重，已结束与待确认使用次要样式，准确状态由 tooltip、读屏及展开说明提供。
菜单提供仅活跃连接和查看所有 App 对此目标的连接；跨 App 时每项保留应用归属，切范围不修改规则。

## 国家图标

用户已放宽为代理服务器所在地／已知本机公网地址的国家，不要求目标网站所见出口。
使用原连接冻结的 remoteDestination 中公开 IP，通过父仓库 Go wrapper 的只读批量接口查询现有本地 MMDB；
不解析节点名称国旗、不使用目标网站地址代替代理地址，不联网解析缺失地址或补下载数据库。
DIRECT、目标同址、私网、域名、未知／查不到时不显示代理国旗。
直连只复用已有、未过期、路由仍有效的 DIRECT 出口检测 IP，再查本地国家；本页不启动公网检测。
国旗 tooltip 和展开详情明确代理服务器或最近本机公网检测的地址来源，不声称是网站所见出口。
离线查询按 128 个地址分批，数据库缺失／损坏返回未知；不把查询放进连接建立热路径。

## 实现与验收

复用 applicationActivityProvider 的有界运行期数据，保留 App／Host／Native 实例上下文；不新增观察器、轮询、服务控制或来源接受。
连接缺少 URL、HTTP 状态码、请求耗时、精确结束时间和最终流量时不猜测补齐。
验证两个 App 同 Host 的隔离及跨 App 范围、相同 IP 不同 ID 不合并、快照流量更新、停止／失败不误判结束、
新实例／清空后的空态、展开重排、返回搜索／滚动、复制失败、窄屏大字体和四种本地化。
国家查询验证本地数据库结果、缺失／坏库、超限、非公网、DIRECT、目标 IP 误用反例及 API 协议一致性。
完成后维护当前 Design／Overview／Tasks，记录验证边界，并安装现有 AVD 的最新测试包。
