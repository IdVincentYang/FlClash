标题打开完整列表，应用 item 的主体、策略标题和开关与完整列表共用实现；卡片只限制最多三项。

从应用网络打开详情时可返回已有页面。旧记录、目录失败及未知／共享身份保留真实范围。
卡片渲染不增加观察任务或出口检测，等待既有启动恢复完成后再读取活动依赖。
