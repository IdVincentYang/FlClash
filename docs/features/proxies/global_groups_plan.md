# 全局用户分组

用户分组定义独立于订阅保存。切换订阅后仍能看到原组，并通过原引用管理页加入新订阅的 Selector。
保留订阅配置模式，成员仍只来自当前已加载且获许可的订阅，不引入跨订阅节点池。

## 数据与采用

- 数据库增加全局分组库，作为名称、策略、测试地址、手选名称／正则和排除项的唯一配置来源。
- Profile.localGroups 保留该订阅的引用及上次采用的分组快照；它不是另一份可独立编辑的定义。
  全局编辑同步当前已绑定组；新订阅只在用户添加引用／显式启用时建立绑定。
- 切换就绪后，将已有绑定与全局定义比较，复用原本地差异批准与 Setup 采用流程同步。
  保留旧运行配置直到新配置就绪；校验当前订阅、全局版本、来源及运行意图，迟到任务不能回写。
- 正则针对当前订阅解析；手选名称取当前可用交集。没有可用成员时使用明确的不可用状态／REJECT，
  不猜测替代节点或回落直连。全局定义保留，来源恢复后可以重新解析。
- 各订阅的父入口引用分别保存。全局删除、禁用和重命名保留正在使用的组的原有保护。
  保存定义与运行采用分开反馈；采用失败保留可修改的全局定义，不声称已生效。

## 迁移与备份

一次性收集各订阅原有分组：相同定义合并，冲突定义保留为不同全局组并确定性区分名称。
保留原引用及运行快照，不直接改写正在使用的出口。删除订阅不会删除全局组。
备份包含独立分组库；旧备份仍能提取其分组，只有全局组而无订阅的备份也可恢复。

## 实施顺序与验证

1. 数据库、迁移、备份及纯数据投影：验证多订阅、同名冲突、空库、重复迁移及删除订阅后保留。
2. 成员解析与采用：验证当前订阅隔离、零匹配拒绝、版本变化、失败及旧运行保留。
3. 管理／编辑／引用页：显示同一全局列表，引用随订阅切换，现有定义无损迁移。
4. 相关单元及组件回归、Go 测试、静态分析、生成、APK 构建与现有 AVD 覆盖安装。

上述实施已完成。现行 local_groups_design.md 已更新数据归属、迁移、采用及最终验证结果；历史交付记录保持原验收范围。
